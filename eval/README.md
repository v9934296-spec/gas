# BARZ Phase 0 Real-Audio Dataset

For every take:

1. Record the complete audio.
2. Save the raw STT output unchanged in machine/.
3. Listen to the recording.
4. Write exactly what was spoken in truth/.
5. Do not correct stumbles, slang, repeated words, or ad-libs.
6. Record the environment in meta/.
7. Do not manually calculate WER or edit the machine transcript.

The truth transcript is the human ground truth.
The machine transcript is preserved exactly as produced by STT.
